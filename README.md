# Система управления задачами для небольшой команды

Система собирает работу малой команды (3–15 человек) в одном месте: менеджер создаёт задачи и назначает исполнителей, исполнитель видит свои задачи со сроками и отмечает ход работы, а уведомления, история изменений и отчёты формируются автоматически. Она решает проблему задач, которые теряются в мессенджерах, почте и на стикерах.

Учебный проект по дисциплине «Программная инженерия»: проектная документация без программного кода.

## Пользователи

- **Исполнитель** — член команды, выполняет назначенные ему задачи.
- **Менеджер** — руководитель проекта, ставит задачи и следит за прогрессом команды.
- **Администратор** — управляет учётными записями, ролями и журналом действий.

## Основные возможности

1. Создание задач с описанием, сроком и приоритетом и назначение исполнителя.
2. Список «Мои задачи» с сортировкой и фильтрами по сроку, статусу и приоритету.
3. Смена статуса задачи (новая → в работе → на проверке → выполнена) с комментариями и файлами до 10 МБ.
4. Уведомления в системе и по e-mail: о новой задаче, смене статуса и за 24 часа до срока.
5. Отдельный блок просроченных задач и история изменений каждой задачи.
6. Дашборд менеджера и отчёт по выполненным и просроченным задачам за период.
7. Работа без интернета с синхронизацией после восстановления связи.
