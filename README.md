# Система управления задачами для небольшой команды

Учебный проект по дисциплине «Программная инженерия». Система предназначена для малых команд (3–15 человек) — студенческих, фриланс-объединений, отделов небольших компаний — и собирает их работу в одном месте: менеджер создаёт задачи и назначает исполнителей, исполнитель видит свой список задач со сроками и приоритетами, а уведомления, история изменений и отчёты формируются автоматически. Это решает проблему потерянных задач и забытых дедлайнов, когда работа «живёт» в мессенджерах, почте и на стикерах.

## Основные возможности

- **Для исполнителя:** список назначенных задач, фильтрация и сортировка по сроку, статусу и приоритету, смена статуса (новая → в работе → на проверке → выполнена), комментарии и файлы к задаче.
- **Для менеджера:** создание задач со сроком и приоритетом, назначение исполнителей, объединение задач в проекты, дашборд команды, отчёт по выполненным и просроченным задачам за период.
- **Для администратора:** управление учётными записями и ролями, журнал действий пользователей.
- **Автоматически:** уведомления о новых задачах, смене статуса и приближении срока; история изменений каждой задачи; выделение просроченных задач; сохранение изменений при потере связи и синхронизация после её восстановления.
